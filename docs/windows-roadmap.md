## P0：恢复完整学习闭环（已完成 2026-11-06）

> 完成记录：新增 `WindowsSpeechPracticeBackend`（record 7.1.2），真实录音生成 16kHz/16bit WAV；sherpa-onnx Windows 成功加载 whisper-tiny 模型完成转录与 VAD 测试。首次使用需在「我的 → 语音识别」下载模型；不同麦克风与跟读/复述完整流程仍需人工验收。

### 1. Windows 录音 + 本地 ASR

**现状**

- `lib/services/speech_practice_platform.dart` 的 `isSupported` 只覆盖 iOS / macOS / Android；Windows 上跟读、复述的录音环节会提示不支持。
- 播放、精听、盲听已可用，但「精听 → 跟读 → 盲听 → 复述」闭环无法走完。

**目标**

- 新增 Windows 录音后端，接入现有 `sherpa_onnx` 离线识别，恢复跟读、段落复述、难句补练。
- 录音文件、权限、取消、错误态与现有移动端保持一致。

**建议方案**

- 依赖 `record`（含 `record_windows`）录音到临时 WAV/M4A。
- 实现一个 `SpeechPracticeBackend`（或平台适配层），复用 `lib/services/asr/offline_asr_backend.dart` 与 `sherpa_onnx_engine.dart`。
- 处理：麦克风不可用、权限拒绝、录音中取消、页面退出清理、静音/VAD 结束检测。
- 设置页沿用现有 ASR 模型下载与选择逻辑。

**验收**

- 跟读页可录音、停止后得到识别文本并高亮命中词。
- 复述页可录音、转写并进入评估流程。
- 无麦克风/权限拒绝有明确提示，不崩溃。
- 退出页面后临时录音文件被清理。
- 相关单元/Widget 测试与 Windows 真机烟测通过。

**风险**

- sherpa 模型体积与下载耗时。
- Windows 麦克风设备差异、默认设备切换。
- 录音与播放的时序冲突（复用现有移动端经验）。

## P1：日常可用性（2026-11-06 基本完成）

> 完成记录：Windows 通知提醒已接入并通过调度日志验证（15 条收藏提醒）；本地转录用 ffmpeg-kit + sherpa 实测通过；后台下载器用本地 HTTP 下载实测通过。实际 toast 展示/点击、社区合集下载 UI 端到端、最小化续播仍需人工验收；媒体键 / SMTC 延后 P2。

### 2. 复习提醒 / 系统通知

**现状**：`flutter_local_notifications_windows` 已打包，但运行日志显示 `ReviewReminder ... unsupported`；下载完成通知也未配置 Windows。

**方案**：初始化 Windows 通知（AUMID / GUID），接入复习提醒调度与下载终态通知；处理点击跳转与免打扰。

**验收**：到点提醒可点击进入对应页面；下载完成/失败有系统通知；权限或系统策略不允许时有降级提示。

### 3. 后台播放 + 媒体键

**现状**：音频走 MediaKit 前台播放；`audio_service` 未注册 Windows，锁屏/媒体键/最小化续播未验证。

**方案**：接入 Windows SMTC（System Media Transport Controls）或 MediaKit 的媒体控制能力，补齐播放/暂停/上下句与最小化行为。

**验收**：最小化后继续播放；系统媒体键可控制；播放状态与 App 内一致。

### 4. 本地转录验证与补全

**现状**：`sherpa_onnx_windows` 已打包，本地转录入口存在，但未逐项实测。

**方案**：验证「导入音频 → 下载/选择模型 → 本地生成字幕」；补齐失败提示与取消。

**验收**：无网络也能完成本地转录；模型缺失时有下载引导；失败可重试。

### 5. 社区合集下载 / 更新验证

**现状**：匿名加入社区合集已可用（只写本地占位）；音频批量下载与后续更新未逐项验证。

**方案**：验证加入合集后的下载队列、失败重试、取消、合集更新同步（在匿名公开接口允许的范围内）。

**验收**：加入合集后可批量下载；失败可重试；更新后本地条目正确合并。

## P2：体验与分发

### 6. 应用图标 / 版本信息 / 安装包签名

- 替换 `windows/runner/resources/app_icon.ico` 为 Echo Loop 图标。
- 补全 `Runner.rc` 的产品名、版本、版权信息。
- 安装包代码签名，减少 SmartScreen 警告。

### 7. 自动更新

- 复用现有 AppUpdateChecker / 更新检查逻辑，或接入独立更新源。
- 需要签名与稳定下载地址；未签名前不建议自动静默更新。

### 8. Web 词典 / PDF / 打印实测

- `flutter_inappwebview_windows`、`printing` 已打包；逐项验证网页词典、PDF 导出、打印与分享。

### 9. 窗口行为与桌面体验

- 最小窗口尺寸、单实例、托盘、关闭行为、窗口位置记忆。
- 视需要增加开机自启（默认关闭）。

## 按当前设计不做

| 项目 | 原因 |
|---|---|
| 登录 / 账号 / 云同步 | Windows 版定位本地优先；换机使用备份与恢复 |
| 订阅 / 付费墙 | 不在 Windows 发售；AI 使用用户自定义配置 |
| 云端 AI 转录 / 云端复述评估 | 依赖 Echo Loop 官方后端与账号 |
| 云端 AI 额度 | 自定义 AI 直接请求用户配置的服务，不消耗官方额度 |
